2号館「日替わりメニュー」機能テスト版

1. 5ファイル（index200.html / style200.css / script200.js / admin.html / menu-sync-config.js）をGitHubへpush。
2. 管理者画面で必ず「共有設定を取得」を押し、既存の公開済み設定を取り込む（既存設定を上書きしないため）。
3. 2号館で「肉じゃが定食（仮）」を検索し、表示ON。
4. 「現在の設定を全学生に公開」を押す。
5. 学生画面の2号館・日替わりカードを確認。13号館ではカード非表示。

2号館のみ「日替わりメニュー」カテゴリが選べます。別の商品をそのカテゴリに変更し表示ONにすれば、カードの対象になります。複数ONのときは最初の1品を表示します。日付別の提供管理は未実装で、テスト用として選択日を問わず表示されます。肉じゃが定食の価格・栄養値は仮値です。

注意：管理者側の「共有設定を取得」はローカルの未公開変更を上書きします。
