常翔ウェルフェア v4：日替わり写真＋管理者キー認証

1. GASのCode.gsを同梱版で置き換えて保存（スクリプトプロパティは変更不要）。
2. デプロイ > デプロイを管理 > 編集 > 新バージョン > デプロイ。
3. GitHubリポジトリの同じ階層に admin.html / index200.html / script200.js / style200.css を上書きし、git add ... / git commit / git push origin main。
4. 管理画面を開き、ADMIN_KEYを入力して「認証する」。認証済み表示を確認。
5. 2号館の日替わりメニューの編集で画像をアップロード → 内容を保存 → 全学生に公開。
6. 学生画面を再読み込みし、2号館の日替わりカードに写真が大きく表示されるか確認。

注：写真はGoogle Driveの共有設定やブラウザの画像読み込み制限によって表示できない場合があります。その際は絵文字に戻ります。
注：キー認証は画面の操作確認用です。GAS側で各更新要求のキーを引き続き検証します。公開されたHTML自体は誰でも閲覧できます。
注：日替わりの提供日指定はまだ未実装です。
